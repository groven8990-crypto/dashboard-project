# 매출·마진 대시보드

온라인판매 유통회사용 매출/매입 대시보드. 2개 사업자를 통합 관리하고,
일/주/월/연 단위로 마진 구조를 분석합니다.

## 주요 기능

- **종합 대시보드**: 매출·매입·순마진 KPI 카드, 추이 차트 (일/주/월/연)
- **마진 구조 분석**: 매입·인건비·광고비·판매수수료·부가세를 제외한 순마진액·마진율
- **사업자·채널 비교**: 2개 사업자 + 판매 채널(스마트스토어/쿠팡 등)별 실적
- **일일 매출 보고**: 매일 보고용 리포트 (전일/전주 동요일/월 누계 비교, 인쇄·복사 지원)
- **데이터 관리**: CSV/엑셀 업로드, 수기 입력, 템플릿 다운로드, 내보내기
- **자동 헤더 인식**: `날짜/매출/매입/인건비/광고비/판매수수료/부가세` 등 한글 헤더 자동 매핑
- **로컬 저장**: 데이터는 브라우저 localStorage에 저장 (서버 불필요)

## 마진 계산식

```
순마진액 = 매출 − 매입 − 인건비 − 광고비 − 판매수수료 − 부가세
순마진율 = 순마진액 ÷ 매출 × 100
매출총이익률 = (매출 − 매입) ÷ 매출 × 100
```

## 실행 방법

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 접속.

## 데이터 형식

CSV 또는 엑셀(xlsx) 파일. 한글 헤더 자동 인식:

| 컬럼 | 인식되는 헤더명 |
|---|---|
| 날짜 | 날짜, 일자, 거래일, 판매일, 주문일 |
| 사업자 | 사업자, 사업장, 법인, 브랜드, 회사 |
| 채널 | 채널, 판매채널, 플랫폼, 쇼핑몰 |
| 매출 | 매출, 매출액, 판매액, 주문금액, 결제금액 |
| 매입 | 매입, 매입액, 원가, 상품원가 |
| 인건비 | 인건비, 급여, 인력비 |
| 광고비 | 광고비, 마케팅비, 광고 |
| 판매수수료 | 판매수수료, 수수료, 플랫폼수수료 |
| 부가세 | 부가세, 부가가치세, 세금 |

처음 사용하시면 **데이터 관리 > 🧪 샘플 데이터 로드**로 데모를 먼저 확인해보세요.

## 일일 보고 작성 흐름

1. `데이터 관리` 탭에서 당일 매출/매입 입력 (또는 CSV 업로드)
2. `일일 매출 보고` 탭에서 보고일자 선택
3. `📋 텍스트 복사`로 메신저용 보고 텍스트 즉시 복사 또는 `🖨️ 인쇄`로 PDF/출력
